# arr-max.github.io

Сайт **Команда Арр Макс** — строительные работы и укладка каменных ковров по технологии TerraWay®.

## О проекте

- **Языки:** русский и английский (переключатель в шапке, флаги RU / England).
- **Секции:** кейсы с галереей и названиями объектов, hero с типографом фраз, технология TerraWay, преимущества, раздел о пользе ходьбы по покрытию для тела и самочувствия, области применения, услуги, контакты.
- **Кейсы:** загружаются из `cases/cases.json`, у каждого объекта есть `title` и `titleEn`; подписи под фото (результат / в процессе / начало) и метаданные переводятся при смене языка.
- **Hero:** эффект печатной машинки с пятью зацикленными фразами (RU/EN), шрифт Oswald.

## Технология TerraWay

Водопроницаемая система мощения для территорий с лёгкой нагрузкой: дорожки, парковки, велодорожки, площадки у бассейнов, крыльцо и др. Высокая водопроницаемость (~1800 л/м²·ч), прочность, класс противоскольжения R11, экологичность и простой уход.

## Стек и структура

- Статический сайт: `index.html`, `styles.css`, `script.js`, `translations.js`.
- Локализация: `window.ARRMAX_I18N` (ru/en), переключение по тумблеру с сохранением в `localStorage`.
- Кейсы: данные в `cases/cases.json`, фото в папках `cases/case_*` и `back/`.

## Запуск

Откройте `index.html` в браузере или разместите репозиторий на GitHub Pages (сайт доступен по адресу https://arr-max.github.io).
