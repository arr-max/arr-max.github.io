# arr-max.github.io

Сайт **Arr Max** — строительные работы и укладка каменных ковров по технологии TerraWay.

## Содержание

- Описание технологии TerraWay® (водопроницаемость, прочность, экология)
- Преимущества и области применения
- Услуги: укладка каменных ковров, строительные работы, обслуживание покрытий
- Контакты

## Технология

TerraWay — водопроницаемая система мощения для территорий с лёгкой нагрузкой (дорожки, парковки, велодорожки, площадки). Высокая водопроницаемость, прочность, экологичность и простой уход.

## Запуск

Откройте `index.html` в браузере или разместите репозиторий на GitHub Pages.
