# Changelog & roadmap

Задачи и идеи для развития сайта **Команда Арр Макс**.

---

## Сделано

- Сайт на RU/EN с переключателем языка (флаги RU / England).
- Секция кейсов: галерея, табы, названия объектов (Балкон, Выезд, Крыльцо и др.), перевод при смене языка.
- Hero с эффектом печатной машинки (5 фраз по кругу).
- Раздел «Тело и забота о себе» — польза ходьбы по естественному покрытию (RU/EN).
- Описание технологии TerraWay, преимущества, области применения, услуги, контакты.
- Favicon, исправление ошибок в консоли, мобильное меню.

---

## В планах (актуальные задачи)

### Контент и SEO
- [ ] Заполнить в кейсах реальные данные: площадь, сроки, стоимость, локация, материал (или скрыть пустые поля).
- [ ] Добавить уникальные meta description и Open Graph для главной и при расшаривании ссылки.
- [ ] Проверить заголовки (h1–h3) и структуру для поисковиков.

### Формы и контакты
- [ ] Проверить работу формы «Узнать стоимость» (Google Forms) на десктопе и мобильных.
- [ ] При желании — простая форма «Оставить заявку» с отправкой в Telegram или на почту (без тяжёлого бэкенда).

### Производительность и доступность
- [ ] Оптимизировать изображения в кейсах (WebP, сжатие, lazy-load при скролле).
- [ ] Проверить контраст текста и кнопок (WCAG AA).
- [ ] Убедиться, что типограф и карусель не ломают навигацию с клавиатуры и скринридером.

### Контент и дизайн
- [ ] Обновлять кейсы по мере появления новых объектов (фото + запись в `cases.json`).
- [ ] При необходимости — блок «Отзывы» или «Вопросы и ответы».
- [ ] Регулярно обновлять README и CHANGELOG при крупных изменениях.

### Технические
- [ ] При росте числа кейсов — пагинация или «Показать ещё» вместо всех табов в одну строку.
- [ ] Рассмотреть простую аналитику (например, счётчик посещений без персональных данных).
